# Archived manual SQL scripts

These two files used to be pasted by hand into the Supabase SQL Editor. Their contents now live in
`supabase/migrations` (`00012_account_applications.sql` and `00013_application_documents.sql`), which is the
single source of truth for both Docker (`supabase db reset`) and Cloud (`npm run db:cloud-sql`).

Kept only for reference. **Do not run them** — they are older and would reset storage limits.
